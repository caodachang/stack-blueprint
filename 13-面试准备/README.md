# 面试准备

本目录用于整理求职与技术面试所需知识，包括简历项目复盘、技术问答、项目演示、岗位专项准备和模拟面试记录。

## 建议内容

1. 简历项目复盘
2. Python 与 FastAPI
3. React 与前端基础
4. PostgreSQL、SQLite 与向量数据库
5. RAG、LangGraph、Agent 与 Tool Calling
6. Git、Linux、Docker 与部署排障
7. 计算机网络、操作系统与数据库基础
8. 行为面试与自我介绍
9. 面试问题记录与复盘

知识型内容继续遵循项目根目录 `README.md` 的规范，优先使用 `.ipynb`；清单、题库和面试记录可使用 `.md`。

## 当前笔记

1. `01-GB-Agent项目复盘.ipynb`：项目架构、Agent 主链路、RAG、数据存储、SSE、工程化、真实边界与面试问答。
2. `02-AI应用全栈开发面试八股.ipynb`：针对岗位的 Python、FastAPI、网络、数据库、前端、RAG、Agent、Git、Linux、Docker 与行为面试高频题。
