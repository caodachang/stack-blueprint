# 全栈名词学习笔记

## 项目定位

这是一个面向 AI 协作开发时代的软件开发通识手册，目标是帮助读者从“听到开发术语会卡住”，走到“能把模糊想法写成人能评审、AI 能执行、结果能验收的软件规格”。

## 完整目录

完整目录见 [目录.md](目录.md)。

## 文件名

- 前面带编号
- 使用 `.ipynb` 文件
- 表达清楚主题

## 写作规则

### 1. 文件格式

> 目的是易读

- 只使用 markdown cell
- **命令、代码、配置**要写在相应的 markdown fenced code block 中

### 2. 全面且简洁

**知识足够全面，多一句没有，少一句不行**

### 3. 从名词开始

- 每篇笔记从专有名词开始
- 从历史角度解释为什么需要它
- 它是什么，需要适当的横向对比
- 它怎么用

### 4. 递归解释

解释 A 时遇到 B，简要解释 B

### 5. 与面试相关内容适度扩展

如果某篇笔记里**恰好有面试高频点**，在笔记里给出提示

### 6. 默认标记

>表示示例

能用文字很好的表述就不用表格

### 7. 边界条件

注意前后笔记，知识点不要在不同笔记中重复

不要“先说结论”，新手真的容易有误区才要“写手常见误区”，不要“和 AI 协作时怎么说”，不要“读完能做到”，真的有面试高频点才要面试提示
